# Product Truth — Isha Rose Wilson Portfolio

## Summary
Personal developer portfolio website for Isha Rose Wilson, a B.Tech Computer Science and Engineering student at Government Engineering College Wayanad based in Kozhikode, Kerala, India.

## Target Audience & Goals
- **Audience**: Tech recruiters, engineering managers, open-source collaborators, and peer developers.
- **Visitor Goal**: Quickly evaluate technical capability, view real shipped projects on GitHub, assess code quality, and reach out via email/LinkedIn.
- **Product Position**: Clean, calm, high-performance web developer crafting intuitive interfaces with React, TypeScript, and modern web tools.

## Platform & Technical Constraints
- **Platform**: Web (`web`)
- **Stack**: React 19 + TypeScript + Vite + Tailwind CSS v4 + Framer Motion
- **Deployment**: Static single-page application (GitHub Pages / Vercel compatible)

## Shipped Projects (Product Proof)
1. **Carzone** (`https://github.com/isharosewilson/carzone`) — CSS/HTML car showcase UI
2. **Calculator** (`https://github.com/isharosewilson/calculator`) — Interactive HTML/JS calculator
3. **Fortune Tours** (`https://github.com/isharosewilson/Fortune-tours`) — Travel agency showcase landing page
4. **Vibe Coding** (`https://github.com/isharosewilson/vibe_coding`) — Creative TypeScript utilities & web explorations

## Brand & Visual Commitments
- **Style**: Ultra-minimalist, Apple-style simplicity, zero clutter, generous whitespace, confident typography, smooth non-distracting scroll animations, restrained monochromatic base with single Apple Blue accent (`#0071E3`).
- **No Purple / Multi-color Gradients**: Pure clean monochrome + Apple Blue tone.
- **Real Assets**: Real profile photo in About section (`/avatar.jpg`).
